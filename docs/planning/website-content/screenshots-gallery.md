# Screenshots Gallery — stub

**Target page:** `/gallery/_index.md` (new) on chartedroots.com
**Status:** 📋 Stub — Phase 3, non-urgent.

---

## Purpose

Visual tour of the plugin — answers the "what does it actually look like?" question that the feature descriptions can't fully convey. Particularly helpful for prospective users deciding whether to install.

---

## Proposed sections

- **Canvas Tree** — Standard, Compact, Timeline, Hourglass layouts, plus a multi-generation tree.
- **Family Chart view** — live exploration, color schemes (gender / generation / collection / monochrome).
- **Interactive map** — migration paths, heat maps, time-slider animation, custom image maps for fictional worlds.
- **Entity Profile View** — one screenshot per entity type (person, place, event, source, organization).
- **Edit Person modal** — relationships, dates, sources. Possibly the universe dropdown if universes are active.
- **Control Center** — Collections tab, Sources tab, Places tab, Events tab.
- **Reports** — pedigree chart, family group sheet, source summary, a couple more from the 17+ catalog.
- **Book Builder** — one screenshot of a compiled narrative output.
- **Calendar View** — real-world + fictional calendar side by side.

## Notes for capture session
