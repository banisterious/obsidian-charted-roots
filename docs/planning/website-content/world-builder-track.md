## Purpose

Dedicated page for the world-building audience — writers, game-masters, fictional-universe historians. The main landing page serves both tracks; this page goes deep on the worldbuilding-specific features and shows how they chain together into a workflow.

---

## Proposed structure

1. **Opening frame** — one paragraph explaining the track: Charted Roots works as a genealogy tool *and* a worldbuilding tool, and the same feature set (family trees, places, events, sources) maps cleanly onto both. Worldbuilders get additional tools specific to fictional settings.
2. **Universes** — what a universe is in Charted Roots, how to create one, scoping entities to it, the universe wizard.
3. **Custom calendars and fictional date systems** — BBY/ABY / TA / AC-style eras, the date system dropdown, universe-scoped auto-detection. Note: this feature has some rough edges (see issue #432) — worth a soft mention on "what's coming" once #432 lands.
4. **Custom image maps** — pixel-coordinate maps for fictional worlds, the map creation wizard, waypoint authoring.
5. **Book & Narrative Compilation** — compiling a universe's notes into a narrative export.
6. **Entity Profile Views** — especially useful for worldbuilders building out deep fictional biographies.
7. **Example workflow** — a short worked example ("Build a Star Wars family history in 15 minutes") or screenshots of a sample universe.
8. **Related research features that work for fiction too.** A sidebar or callout noting that GEDCOM export, the sources subsystem, and canvas trees all work the same whether the data is factual or fictional. Link to [research-track.md](research-track.md) for the evidence workflow deep dive.
